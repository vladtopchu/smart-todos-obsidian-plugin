# Установка Smart Todo 1.0.3

Один архив подходит для macOS, Windows, Linux, Android и iOS. Нужен Obsidian 1.8 или новее. Node.js и сборка на устройстве не нужны. Проверка на физическом телефоне пока не проводилась.

Название в Obsidian: **Smart Todo**. ID плагина: `smart-todos`. Не переименовывайте папку и не меняйте ID в manifest.json.

## Установка из каталога

Откройте Settings → Community plugins → Browse, найдите **Smart Todo**, нажмите Install, затем Enable. Инструкция ниже нужна для ручной установки из архива.

## Другой ноутбук

1. Распакуйте архив.
2. Откройте папку нужного хранилища. Включите отображение скрытых файлов, чтобы увидеть `.obsidian` (на macOS — Cmd+Shift+.). Если в Obsidian задана другая папка конфигурации, используйте её вместо `.obsidian`.
3. Скопируйте папку `smart-todos` целиком в `<хранилище>/.obsidian/plugins/`. Если `plugins` ещё нет, создайте её. Итоговый путь: `.obsidian/plugins/smart-todos/manifest.json`. Вложенной второй папки с тем же именем быть не должно.
4. Перезапустите Obsidian. В Settings → Community plugins разрешите сторонние плагины и включите **Smart Todo**.
5. В палитре команд выберите **Smart Todo: Открыть планировщик**.

## Телефон

Скопируйте ту же папку плагина в папку конфигурации хранилища телефона, затем перезапустите Obsidian и включите **Smart Todo** в настройках сторонних плагинов.

- **Android:** используйте файловый менеджер с отображением скрытых файлов. Папка назначения: `<хранилище>/.obsidian/plugins/smart-todos/`.
- **iPhone/iPad:** если файловый менеджер не даёт доступ к `.obsidian`, перенесите папку конфигурации с компьютера через используемое средство синхронизации, поддерживающее такие файлы. В Obsidian Sync для этого включите **Installed community plugin list** и **Active community plugin list** в разделе Vault configuration sync ([официальная инструкция](https://help.obsidian.md/sync/settings)). Обычная синхронизация Markdown-заметок сама по себе не гарантирует передачу плагинов. После передачи проверьте включение Smart Todo на телефоне.
- Добавьте команду **Smart Todo: Открыть планировщик** в мобильную панель инструментов для быстрого доступа.

## Данные и настройки

Архив содержит только код плагина, manifest.json, стили, инструкцию и контрольные суммы. Личных задач и настроек в нём нет.

Для одинаковых задач на устройствах синхронизируйте папку `_todotracking` (или выбранную папку планировщика). Путь настраивается в Smart Todo. Если нужен перенос самих настроек, отдельно скопируйте `data.json` из папки плагина установленной копии. При обновлении не заменяйте его.

Файлы прежней нашей сборки с типами `dayline-task`, `dayline-goal`, `dayline-habit` продолжают читаться без переименования. Папка публичного плагина `dayline` не используется новой сборкой и не изменяется её установщиком.

## Переход со старого ID

Если установлена сборка с ID `smart-todo-vlad-9c82e1b4`, отключите Smart Todo и закройте Obsidian. Переименуйте её папку в `.obsidian/plugins/smart-todos`, затем скопируйте туда новые `main.js`, `manifest.json`, `styles.css`. Сохраните `data.json`: это настройки плагина. Запустите Obsidian и включите Smart Todo заново. Папку с заметками переносить не нужно. Старый ID содержал цифры, которые не допускаются текущими [правилами manifest](https://docs.obsidian.md/Reference/Manifest).

## Обновление нашей сборки

Отключите Smart Todo в Obsidian, замените только `main.js`, `manifest.json`, `styles.css` в папке `smart-todos`, затем включите плагин. Сохраните `data.json` и папку с заметками. Новые версии устанавливайте через Community plugins или из архива с тем же ID.

Файл `SHA256SUMS` позволяет проверить содержимое после распаковки: `shasum -a 256 -c SHA256SUMS` на macOS/Linux.
